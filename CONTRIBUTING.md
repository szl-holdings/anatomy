# Contributing

**Control before action. Evidence after.**

Living Anatomy is a **3D observation atlas**, not the fail-closed kernel and not a promotion console.

1. State the invariant (test or Evidence Bay contract) before changing FE/BE.
2. Never paint UNKNOWN/DOWN organs green. Energy stays `UNAVAILABLE` unless MEASURED.
3. Canonical surfaces: https://a-11-oy.com · https://a11oy.net.

Branch as `szl/<change>` or `rosa/<change>`; Conventional Commits; PR-only to default.
